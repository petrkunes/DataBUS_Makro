# DataBUS_Makro

Upload of the Czech plant-macrofossil file to the
[Neotoma Paleoecology Database](https://www.neotomadb.org) with [DataBUS](https://github.com/NeotomaDB/DataBUS).

## Setup

```bash
uv sync --extra dev   # Python 3.11.10, DataBUS from git
```

`.env` (gitignored) needs `PGDB_TANK`: a JSON object passed to `psycopg2.connect`. (Or `PGDB_LOCAL` if working in production).

## Workflow (run from the repo root)

```bash
uv run src/prepare_makro.py
uv run src/check_variables.py
# read-only: which taxa / variables are missing in Neotoma -> data/CZ_makro_missing_variables.csv
uv run src/template_validate.py
# pass 1: validate only (always rolled back); writes data/CZ_makro_long.csv.valid.log
uv run src/template_validate.py --upload true
# pass 2: commits only if pass 1 was clean for this exact file
```

Read the `✗` lines of the `.valid.log`; `?` lines are warnings, `✔` lines are OK.

A taxon or variable that is not in Neotoma is reported in the log as `Valid: FALSE` for it.

The upload (pass 2) only commits once everything is valid.

## Files

| Path | Purpose |
|---|---|
| `data/CZ_makro_short.csv` | Raw export, long format, not edited |
| `data/CZ_makro_long.csv` | The raw rows and columns, unchanged, plus 7 added columns: `taxon`, `element`, `value`, `units` and the contacts `collector`, `datasetpi`, `sampleanalyst` (as `Family, I.`) |
| `data/CZ_makro_missing_variables.csv` | Generated by `check_variables.py`: Lists each missing taxon / variable |
| `data/CZ_makro_long.csv.valid.log` | Written by `template_validate.py` |
| `src/templates/template.yml` | DataBUS mapping; the depth has `groupby: true` so rows with the same depth are one sample |
| `src/prepare_makro.py` | Adds the columns above: Czech taxon / element code -> Neotoma name, count/weight -> value + units, contact formatting. The translations are listed in `REPORT.md` |
| `src/check_variables.py` | Read-only check of taxa and variables against Neotoma |
| `src/template_validate.py` | The two-pass validator/uploader |
